# Contributing to Resume

Thank you for your interest in improving this LaTeX Resume repository!

## 🚀 How to Contribute

1. **Fork and Clone**
   - Fork this repository on GitHub.
   - Clone your fork locally:
     ```bash
     git clone https://github.com/bino369/Resume.git
     cd Resume
     ```

2. **Create a Feature Branch**
   - Create a dedicated branch for your change:
     ```bash
     git checkout -b fix/your-improvement
     ```

3. **Make and Test Changes**
   - Edit `Binoy_Anil_Resume.tex` or documentation files.
   - Compile locally to verify formatting and ensure zero TeX errors:
     ```bash
     ./compile.sh
     ```
   - Ensure the generated `resume.pdf` remains visually clean and fits on a single page.

4. **Commit and Open a Pull Request**
   - Write clear, descriptive commit messages.
   - Push your branch to GitHub and open a Pull Request against `main`.
